## 1. 状态定义

- `未开始`：没有实现或证据。
- `进行中`：已经有实际代码，但验收未全部通过。
- `完成`：实现、测试、构建和对应文档全部通过。
- `阻塞`：存在明确外部依赖或规则裁决。

- 网络连接与 Sim 玩家实体分离管理；断线只解除 socket 绑定，不重新加入玩家，也不重置血量、冷却、装备、随机流或回放花名册。
- 断线时权威端提交下一序列的静止意图，恢复响应返回该确认序列，客户端从下一序列继续发送。
- 提供 120 秒恢复宽限期和 `connected/disconnected/expired` 会话状态；请求到达时会再次核对绝对截止时间，不只依赖定时器。
- 浏览器在线身份和令牌按服务端地址保存在当前标签页 `sessionStorage`，刷新或短暂断网后自动恢复原实体。
- 支持刷新竞态下的新连接凭有效令牌接管旧连接；旧连接收到 `SESSION_REPLACED`，令牌轮换后不能再次接管。
- 恢复窗口过期后凭证失效，但当前没有擅自增加“断线淘汰”规则；实体保持静止并继续受权威 Sim、其他玩家和雷暴影响。

## 8. 已知非阻塞技术债

- Web V1 首包约 212 KB，gzip 约 48.8 KB；约 1.25 MB 的战斗运行时动态加载。
  本轮生产 HTTP/CDN/浏览器已复验入口和资源可用性；缓存命中、首屏加载和
  低端设备热稳态仍需独立的真实网络与真机采样。
- 当前客户端默认运行在线权威宿主；浏览器本地开发与离线回归通过 `?mode=local`
  显式启用，不再为 Web 路径补产品化模式 UI。
- 当前 Unity 工程已有 423 Agent 客户端开发机样本，但没有完整玩法、动态实体峰值、
  GPU 帧时、Release GC 或真机热稳态；所有发布性能预算仍是待验证目标。
- 当前 Windows 机器不能完成最终 iOS 签名和真机发布，U4/U7 前必须准备 macOS、
  Xcode 和 iOS 设备。
- 当前灰盒视觉用于验证规则和输入，不代表最终美术质量。
- 当前 14 阶段伤害只闭合代表子链，尚未覆盖全部闪避、固定减伤和比例减伤内容。
- D6 已有可哈希、可回放的静态矩形后端；普通移动、视线、普通弹道、冻河和正式地图墙体统一碰撞仍等待 M3。
- 普通弹道基础寿命仍是临时裁决，等待真源增加独立字段。
- 当前已有硬控中断旋风的运行时入口，但 M1 代表内容中还没有可施加硬控的完整主动。
- 当前网络协议为版本化 JSON v7；在线 `ClientWorld` 基础快照和会话恢复已完成，插值、预测、消息限流、房间复用和生产 Protobuf 迁移尚未完成。
- 恢复窗口过期后只使网络凭证失效，不会自动删除或淘汰 Sim 实体；正式处置规则仍需真源裁决。
- 恢复会立即下发最新权威快照，但断线期间已错过的瞬时 HUD 事件不会补发；后续需要事件游标或可重放事件窗。
- 唯一胜者和全员同 tick 淘汰平局已闭合；并列冠军和同名次规则仍属于 M6。
