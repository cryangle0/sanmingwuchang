## 6. 未关闭风险

1. 真源对被动内置 CD 的真死行为仍有冲突；开发暂按继续剩余 CD。
2. 生命舍入规则仍有两套表述；M0 只提交整数伤害，五行乘算暂向下取整。
3. 单位闭合集合仍缺 `1/s`、`hp/s`、`deg/s` 和 `pct/s`。
4. 正式地图有 31 条重复边和九个墙 ID 冲突，M0 未导入正式地图。
5. 生产协议仍是调试 JSON，M1/M2 需要替换为 Protobuf。
6. Web 包当前约 534 KB，gzip 约 137 KB，需要在 M1 做分块和加载优化。
