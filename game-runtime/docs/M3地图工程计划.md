# M3 百眼迷城地图工程计划

日期：2026-07-25
状态：执行中
前置基线：`bb926a6`（87 项测试通过）

## 1. 问题

- 真源地图 v2 工程 JSON（199 节点 / 342 边 / 42 墙）已解决 MAP-001/MAP-002 的
  重复边与墙 ID 冲突，但当前内容编译器把任意多边形墙（最多 61 顶点）压成
  轴对齐包围盒，几何严重失真，不能作为 M3 的权威碰撞。
- Sim 边界仍是圆形竞技场；弹道不与静态墙碰撞；出生点是 M0 圆环点，
  未使用地图的 30 个出生微位。
- 客户端渲染器是 1000 行单体，没有地图渲染架构。

## 2. 设计决策

### D-M3-1 凸多边形分解（编译期）

墙多边形在编译期做确定性耳切三角化 + 贪心凸合并，输出整数毫米凸片段
（每片段带父墙 ID 与稳定序号）。验证门槛：片段全凸、面积和等于原多边形、
顶点全整数、无重复 ID。

### D-M3-2 整数凸几何（运行期）

`packages/sim/src/geometry/` 提供纯整数几何原语：点在凸多边形内、圆与
凸多边形最近距离与推出、线段对凸多边形的扫掠首触。坐标绝对值 ≤ 45 万 mm，
64 位浮点整数域内叉积精确，跨平台确定。空间哈希网格做宽相。

### D-M3-3 地图是比赛配置，不替换 Oracle 行为

现有圆形竞技场、M0 出生点与全部既有测试合同不变。百眼迷城通过
`SimulationOptions.map` 开启：多边形边界取代圆边界、凸片段墙体接入
移动/闪现/弹道、地图出生微位取代 M0 圆环。默认不开启。

### D-M3-4 渲染模块化

`apps/web/src/render/map/` 按职责拆分：材质库、地面构建器、墙体挤出
构建器、高台与坡道构建器、POI 标记、装饰散布。ArenaRenderer 只做组装。

## 3. 阶段

| 阶段 | 内容 | 验收 |
|---|---|---|
| P1 | `tools/map/` 几何编译器：多边形校验、三角化、凸合并、整数化，生成 `map-geometry.generated.ts` | 编译器单测 + 生成物校验测试 |
| P2 | `packages/sim/src/geometry/` 整数凸几何 + 网格索引 | 单测覆盖边界值 |
| P3 | Sim 接入：map 配置、边界、墙体碰撞（移动/闪现/弹道）、地图出生点 | 新增 sim-map 测试；千种子回放不回归 |
| P4 | Three.js 地图渲染模块族 + 小地图 | 桌面/移动截图验收 |
| P5 | Unity 目录再生成（凸片段）+ 灰盒场景工厂消费 + 几何 Golden Fixtures | unity EditMode 对拍 |
