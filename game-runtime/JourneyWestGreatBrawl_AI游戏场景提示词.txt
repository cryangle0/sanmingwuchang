# ================================================================
# JourneyWestGreatBrawl / 《三命无常》
# AI 游戏场景视觉提示词
# ================================================================

用途：
将以下内容作为本项目的统一场景生成提示词。用于生成大厅、选角页背景、
战斗地图、区域概念图、地图资产设计、宣传图和关卡美术方案时，必须保持
同一套世界观、镜头语言、色彩系统和空间层级。

项目简称：
JourneyWestGreatBrawl

中文项目名：
《三命无常》

核心原则：
这是一个可以被实际制作和游玩的 3D 游戏场景，不是脱离玩法的纯概念插画。
所有视觉元素都必须服务于游戏识别、路径阅读、战斗可读性、空间导航或环境叙事。

# ================================================================
# 1 PROJECT IDENTITY / 项目定位
# ================================================================

Create a stylized 3D multiplayer PvE battle-royale game scene for
JourneyWestGreatBrawl, the game 《三命无常》.

Genre:
西游神话题材、30 人单人乱斗、PVE 生存、资源争夺、技能构筑、三命制。

Perspective:
固定斜俯视第三人称战斗视角。PC 端允许在有限范围内按住鼠标左键调整观察
方向，滚轮缩放，镜头可以在俯视和较低的贴地水平视角之间平滑变化，但不得
进入第一人称，也不得突破逻辑视野、战争迷雾和锁定规则。

Visual Style:
高质量风格化 3D 游戏场景、东方神话幻想、可读的 PBR 材质、清晰轮廓、
适度细节、真实空间关系、明显的游戏化构图。整体不是照片级写实，也不是
廉价卡通或纯低模。

World Setting:
以西游神话、天庭遗迹、山水秘境、龙宫、古城、森林和天劫决战庭为核心的
东方奇幻世界。

Core Environment:
地图名为“百眼迷城”。这是一座被天劫侵蚀的巨大立体迷城，外围由山谷、
峡谷、城镇、森林、河流、桥梁、商店和怪物巢穴组成，中心分布万劫三庭：
惊蛰庭、玄冥庭、焚天庭。玩家从不同区域出生，在迷雾、怪物、资源和其他
玩家之间规划路线，最终向决赛庭收缩。

The world should feel:
宏大、神秘、危险、鲜活、东方、具有战略性、具有探索价值、空间层次清晰、
繁华与荒败并存、始终有正在发生的事件。

允许使用：
本项目已经确定的西游神话角色、英雄模型、怪物、技能、五行主题和场景资产。

禁止新增：
与项目无关的科幻城市、现代建筑、西式中世纪城堡、赛博朋克霓虹、现代汽车、
枪械、现代广告、其他知名游戏或影视 IP 的角色、标志、服装和可识别视觉符号。

# ================================================================
# 2 THE VISUAL PREMISE / 世界核心视觉概念
# ================================================================

The core visual idea of the world is:

一座连接天庭、山水秘境、古城和龙宫的巨大立体迷城正在天劫中逐步崩解，
玩家沿着可学习的道路、桥梁、坡道和高台穿行，在公开资源和危险事件中
不断选择路线，最终汇聚到中央的万劫三庭。

所有环境设计都必须强化以下关系：

1. 外围区域提供探索、刷怪、商店、宝箱、技能书和装备资源。
2. 中间区域提供道路交叉、伏击、视野交换和公开争夺。
3. 中央高台和决赛庭提供终局压力、BOSS、天劫和最后的生存目标。
4. 地图必须让玩家能够通过道路、墙体、桥梁、地形和建筑识别方向。

不要添加不能解释其功能的随机景物。
不要让美术细节破坏移动、碰撞、视线、技能范围和掉落物的可读性。

# ================================================================
# 3 VISUAL ANCHOR / 核心视觉锚点
# ================================================================

PRIMARY VISUAL ANCHOR:
万劫三庭，尤其是当前比赛阶段对应的中央决赛庭。

视觉表现：
高于外围地形的巨大天庭式石台、环形平台、神殿结构、云海、天光、
金色或青玉色建筑边缘，以及逐渐增强的天劫能量。

位置：
在开放区域和长距离道路中，尽量位于远景中央或偏上方；
被建筑、森林或峡谷遮挡时，使用高台轮廓、天光、云柱、雷云和建筑屋脊
保持方向提示，不要完全失去目标感。

它应该传达：
终点、危险、规模、公共争夺、天命压力和逐步逼近的决战。

SECONDARY FOCUS:
玩家角色、当前可走道路、桥梁、坡道、资源点、商店、怪物群和技能交战区。

TERTIARY DETAILS:
树木、草地、岩石、流水、旗帜、灯笼、屋檐、石刻、云雾、碎片和小型装饰。

视觉层级：
万劫三庭 > 玩家与可交互目标 > 道路和资源节点 > 环境装饰。

不得让树冠、建筑、粒子、UI 叠层或高亮特效遮挡主要道路、玩家轮廓、
技能预警、掉落物和中央视觉锚点。

# ================================================================
# 4 WORLD COMPOSITION / 三层空间构图
# ================================================================

每个主要视图都必须建立清晰的前景、中景和远景。

FOREGROUND / 前景：

玩家当前站立和移动的地面。

可包含：
有起伏的土地、石板路、泥土路、草地、桥面、坡道、平台、浅水边缘、
可辨识的真实曲线水岸、角色脚底定位区域和少量近景植物。

前景要求：
地面必须能读出坡度、方向、碰撞边缘和可通行区域。
水面边缘不得使用长距离僵硬直线，必须采用自然曲线、分段岸线、
浅滩、湿石、草丛和水位过渡。

MIDDLE GROUND / 中景：

中等尺度的导航和玩法对象。

可包含：
树林、岩石、石墙、断桥、木桥、楼阁、城门、商店、宝箱、猪窝、
龙宫入口、伏石、灯笼、旗帜、平台、坡道和怪物活动区域。

中景要求：
对象之间保留可行走间隙，墙体和高台有真实厚度；
建筑、树木和岩石必须支持导航、遮挡、伏击或区域识别。

BACKGROUND / 远景：

长距离环境和世界尺度。

可包含：
万劫三庭、连绵山脉、天庭高台、云海、远处城池、龙宫轮廓、
瀑布、巨大树冠、远方雷云和天劫光柱。

远景要求：
远景必须与中景分层，不要把所有东西堆成一堵平面背景墙。
远景建筑和山体应提供方向感，但不能制造虚假的可通行路径。

# ================================================================
# 5 NEGATIVE SPACE / 留白与空间感
# ================================================================

保留足够的天空、水面、开阔平原、平台和远景云海作为负空间。

负空间用于传达：
地图规模、危险来临前的宁静、探索自由、区域之间的距离、
中央决赛庭的压迫感和玩家相对于世界的渺小。

必须避免：

- 每个角落都塞满树、石头、建筑和粒子
- 过密的装饰导致道路边界消失
- 过多重复的树木、灯笼、旗帜或岩石
- 场景主体被雾、云、特效或高对比装饰覆盖
- 远景没有层次，所有对象都处于同一视觉距离
- 空旷地面没有方向、玩法或叙事作用

开放区域要有呼吸感，关键资源区要有聚焦感，决赛庭要有压迫感。

# ================================================================
# 6 COLOR SYSTEM / 色彩系统
# ================================================================

使用多色分层，禁止整张图只由一种青绿色、蓝色、紫色或棕色组成。

PRIMARY COLOR / 主色：
青玉绿、深青绿、自然草木绿。

主要用于：
森林、草地、远处山体、部分水体和东方神话环境的整体基调。

SECONDARY COLOR / 次色：
暖灰石色、青灰岩石、土黄、深木色。

主要用于：
道路、墙体、平台、桥梁、城镇和山体结构。

ACCENT COLOR / 强调色：
朱砂红、金色、橙色、紫色、五行元素色。

主要用于：
商店、旗帜、技能预警、宝箱、装备稀有度、英雄技能、BOSS 标记和决赛庭。

ARCHITECTURAL COLOR / 建筑色：
青灰石、暗色木材、金色屋脊、青玉边缘、暗红漆面。

主要用于：
天庭楼阁、古城、城门、龙宫、高台、桥梁和神殿。

LIGHT COLOR / 光照色：
暖金日光、浅青天光、白色雷光、橙红火光、蓝紫法术光。

主要用于：
灯笼、窗户、法阵、技能特效、宝石、雷暴和水面反射。

色彩要求：
森林区域偏青绿和暖石色；
城镇与商店区域增加朱砂、金色和木色；
龙宫与水体区域增加青蓝、银色和湿润反光；
万劫三庭增加金色、白色雷光和强烈的五行对比。

每个宽幅镜头至少包含三组可区分色相。
色彩要丰富、干净、饱和度适中，不能浑浊或灰败。

# ================================================================
# 7 LIGHTING / 光线设计
# ================================================================

默认时间：
明亮的清晨至午后；随着天劫阶段推进，可以逐步过渡到更强烈的黄昏、
雷云和终局冷光，但战斗区域始终保持清晰可读。

主光源：
来自天空的暖金色太阳光，方向从画面左上方或侧上方照入。

辅助光源：
云层反射的冷青光、灯笼暖光、商店灯火、技能法阵、宝石光、
五行攻击光、雷暴白光和龙宫水面反射。

光照应产生：

- 角色和树木的清晰轮廓光
- 建筑屋檐和石墙的方向性阴影
- 水面和湿石的高光反射
- 森林缝隙中的局部光束
- 万劫三庭的高空雷光和空间尺度
- 技能预警与实际攻击之间明确的明暗差异

阴影要求：
有层次但不能过黑；玩家、敌人、掉落物、技能范围和道路不能沉入黑色。
不要用大面积雾化或过曝遮蔽信息。

# ================================================================
# 8 MATERIAL SYSTEM / 材质表现
# ================================================================

每类主要材质必须有不同的粗糙度、反射和细节，不要让整个场景使用同一种塑料感。

WATER / 水体：
真实的曲线岸线、浅滩过渡、轻微波纹、法线变化、湿润反射；
水面边缘使用草、泥、湿石和浅色泡沫过渡，不使用大面积矩形水面直线边。

STONE / 石材：
墙体、道路和平台使用青灰或暖灰石材；
表现磨损、裂缝、台阶、湿润区域、边角高光和不同石块尺度。

WOOD / 木材：
桥梁、商店、楼阁和栈道使用有纹理方向的木材；
边缘可以有磨损、漆面脱落和轻微湿润反射。

ROOF AND METAL / 屋顶与金属：
使用深色瓦片、金色屋脊、青铜、铁器和玉石装饰；
金属高光需要克制，不得变成刺眼的纯白塑料。

VEGETATION / 植物：
树干有明显的粗糙度和方向性，树叶有半透明或轻微透光；
树冠要茂盛但保留枝干层次，森林密度分区变化，避免整齐复制。

FABRIC / 布料：
旗帜、帷幔、商店布棚和角色附近装饰具有柔软褶皱和风向。

MAGIC / 法术材质：
技能范围、雷光、火焰、烟雾和宝石使用发光、透明、粒子和边缘高亮；
必须保持形状边界和伤害预警可读，不得用泛白光覆盖整个画面。

# ================================================================
# 9 ENVIRONMENTAL MOTION / 环境动态
# ================================================================

环境应该持续存在轻微、可信、与空间有关的运动：

- 水面波纹沿岸线变化
- 草叶、树叶、旗帜和帷幔受同一主风向影响
- 远处云层缓慢移动
- 森林中有少量粒子、落叶、尘埃和湿气
- 灯笼、法阵、宝石和商店灯火有克制的亮度变化
- 雷暴阶段出现远处闪电、云层亮起和地面短暂反射
- 怪物活动区有脚步、尘土、低频光效和环境反馈

重要互动：

玩家移动 -> 草地轻微摆动、尘土或水面产生小范围反馈。

角色进入浅水 -> 脚边产生小型圆形波纹，不改变角色移动规则。

技能命中地面 -> 地面出现短暂冲击、火花、冰霜、沙尘、烟雾或元素残留。

强风或雷暴 -> 树冠、旗帜、悬挂物和水面同步响应。

不要添加没有来源、没有方向、没有持续规律的随机动画。

# ================================================================
# 10 PLAYER SCALE / 玩家与世界比例
# ================================================================

玩家角色在广阔环境中保持中等偏小的视觉比例。

战斗近景：
角色视觉高度约占画面高度 12% 至 22%，确保模型、脚底定位光效、
攻击动作和技能特效清晰可见。

开放区域宽景：
角色可以缩小到画面高度约 6% 至 12%，用于表现地图规模和路线选择。

角色要求：

- 角色必须站在实际地面或平台上
- 角色脚底的出生/选中/定位光效不遮挡身体
- 光环与地面有明确层次，不能穿过角色主体
- 角色尺寸稳定，不因切换 UI、tab 或镜头轻微变化而跳动
- 所有英雄和怪物保持可辨识轮廓与合理碰撞尺度

世界应该明显大于玩家。

# ================================================================
# 11 CAMERA / 镜头规则
# ================================================================

基础镜头：
固定斜俯视第三人称镜头，保持稳定的战斗阅读方向。

PC 操作：

- WASD 控制移动
- 按住鼠标左键可调整观察方向
- 鼠标滚轮缩放
- 镜头绕玩家平滑跟随
- 上下调整允许接近贴地水平视角，但不得进入第一人称
- 镜头旋转、俯仰和缩放均有边界

移动端：
保留同一逻辑视野、碰撞、技能范围和敌情规则，只改变输入映射和 UI 布局。

镜头行为：

- 角色移动时保持稳定跟随，不产生无意义晃动
- 进入开阔区域时适度拉远，显示道路、建筑和中央地标
- 进入狭窄区域时适度靠近，但不能让角色或墙体遮挡关键目标
- 长距离技能瞄准可以有限地沿瞄准方向前移镜头
- 镜头不能因为宽屏而额外展示敌人、小地图范围或锁定距离
- 镜头不能穿过墙体、地形、建筑或地图边界
- 不使用随机电影式镜头，不改变基础镜头语言

逻辑战斗视口：
以 16:9 为核心规则。更宽的屏幕只增加装饰区域，不改变游戏公平性。

# ================================================================
# 12 FRAMING ELEMENTS / 画面边缘构图
# ================================================================

使用画面边缘元素引导玩家视线，但不要阻挡主路径和视觉锚点：

- 近景树枝和树冠
- 古城门、石柱、楼阁屋檐
- 桥梁和栏杆
- 灯笼串、旗帜和布棚
- 岩壁、山谷和高台边缘
- 水岸植物、湿石和弯曲河岸

边缘元素的作用：
框出玩家前进方向、增强空间深度、暗示区域边界和强调中央决赛庭。

不得：

- 用前景树叶遮挡角色或敌人
- 用装饰性建筑堵住实际可走道路
- 让边缘构图看起来像固定的摄影框，而不是可探索的游戏空间

# ================================================================
# 13 ATMOSPHERE / 氛围控制
# ================================================================

总体氛围：
东方神话的宏大与危险，探索时神秘，战斗时紧张，终局时压迫，
但始终保持清楚的可玩性和信息传达。

雾和云：

- 远景山体、云海和中央高台可以有薄雾
- 森林深处、龙宫入口和峡谷可以有局部雾气
- 天劫阶段可增加雷云、冷色空气透视和高空闪电
- 前景和中景保持清晰、锐利、饱和度可读
- 迷雾不能覆盖已经应该被玩家看到的道路、掉落物、敌人和预警

区域氛围：

断金坡：
低风险、清晰的石坡和断墙，适合玩家理解道路和撤退。

蛛丝峡：
狭窄峡谷、垂直岩壁、蛛网和转角，强调伏击与视线切断。

龙脊渊：
高台、龙宫、水汽和远距离视野，强调高处优势与暴露风险。

百足城：
密集道路、城墙、建筑和多个切入口，强调追击、绕后和资源冲突。

热水市：
商店、桥梁、灯火和公共资源，强调交易、争夺与短暂安全感。

迷魂滩：
森林、猪窝、伏击点和回撤路径，强调探索、风险和方向判断。

万劫三庭：
开放、宏大、雷云密集、地面纹理和建筑尺度明显增强，作为终局舞台。

# ================================================================
# 14 QUALITY RULES / 画面质量和制作规则
# ================================================================

场景必须具备：

- 明确的前景、中景、远景
- 强烈但不混乱的视觉层级
- 可读的角色和怪物轮廓
- 清晰的道路、墙体、坡道、高台和水岸
- 多色相分离的色彩系统
- 统一的光照方向
- 具有差异的材质粗糙度和反射
- 有目的的环境动态
- 可辨识的区域主题
- 能支持战斗、导航、资源争夺和环境叙事的布局

每个物体至少满足以下一个条件：

1. 支持玩法，例如道路、遮挡、碰撞、商店、宝箱、怪物巢穴或资源点。
2. 支持构图，例如引导视线、建立前中后景或强调视觉锚点。
3. 支持环境叙事，例如天庭遗迹、龙宫、水患、战斗痕迹或天劫侵蚀。

不满足以上条件的对象应该删除或合并。

游戏化制作要求：

- 角色、怪物、建筑、树木和水体需要可被游戏引擎使用
- 高密度对象应考虑实例化、LOD、材质复用和分区加载
- 不使用无法优化的大面积透明叠层
- 不用高亮、雾、粒子和后处理掩盖几何问题
- 远景可以简化，但不得与可玩区域产生错误的路径暗示
- 视觉效果必须服从 30 人、PVE 怪物和技能特效同屏的性能目标

# ================================================================
# 15 NEGATIVE ART DIRECTION / 禁止的视觉方向
# ================================================================

避免：

- 现代城市、科幻机械、赛博朋克霓虹、枪械和现代交通工具
- 西式中世纪城堡、欧洲街道和与西游题材无关的建筑语言
- 纯照片写实、廉价卡通、塑料感低模和无材质细节
- 大面积灰雾、灰蒙、低对比和失去轮廓的阴影
- 只使用深青绿色或只使用紫色的单一配色
- 矩形水面、长距离直线水岸和硬切地形边缘
- 所有树木、岩石、建筑完全复制的重复布局
- 填满画面的随机道具、树叶、粒子、灯笼和浮空碎片
- 过大的角色、过亮的技能、遮挡视野的特效
- UI 面板、文字、按钮和装饰覆盖游戏场景主体
- 虚假的可通行道路、悬空建筑、没有厚度的墙体
- 与实际碰撞、视线、技能范围不一致的视觉表现
- 过度倾斜、第一人称、晃动、旋转失控或突然改变的镜头
- 把万劫三庭做成与周围地图无关的孤立平台
- 只追求概念图华丽而忽略游戏导航、性能和战斗可读性

不要让场景感觉：
泛化、空洞、浑浊、杂乱、廉价、过度拥挤、没有方向、
没有玩法、没有东方身份或无法真正落地制作。

# ================================================================
# 16 FINAL VISUAL GOAL / 最终画面目标
# ================================================================

The final game world should feel like:

玩家正在一座被天劫逐步吞噬的东方神话迷城中求生；
脚下是有真实起伏、道路、墙体、桥梁和曲线水岸的可玩地图，
远处是高耸的天庭决赛庭、云海和雷云；
森林、城镇、龙宫、商店、怪物和公开掉落共同构成一场持续变化的路线选择。

玩家应该立即理解：

WHERE THEY ARE / 我在哪里：
我在百眼迷城，一座连接山水秘境、古城、龙宫和天庭高台的西游神话战场。

WHERE THEY ARE GOING / 我要去哪里：
我需要根据当前安全区、资源、敌人和天劫方向，逐步向万劫三庭和最终决赛庭靠近。

WHAT MAKES THIS WORLD UNIQUE / 这个世界独特在哪里：
三条命、战争迷雾、固定容量 PVE、公开资源、五行克制、英雄技能、
移动商店、宝箱与掉落、真实地形和逐步增强的天劫共同构成持续的战略压力。

最终画面必须同时具备：
西游神话身份、可玩的空间结构、明确的远景目标、丰富但受控的色彩、
真实的材质差异、自然的水体和森林、清楚的战斗信息以及可落地的性能意识。

# ================================================================
# 可选场景变量 / SCENE VARIANTS
# ================================================================

生成具体场景时，在上述统一规则基础上选择一个场景类型：

LOBBY / 大厅：
重点表现天庭大厅、中央圆形平台、远处云海和英雄展示空间；
画面开阔、光线明亮、压低战斗特效密度，突出进入对局的仪式感。

HERO SELECTION / 选角：
重点表现角色卡片、英雄展示台、背景天庭建筑和清晰轮廓；
角色是主焦点，背景必须简洁，不能抢夺英雄模型和技能信息。

BATTLE MAP / 战斗地图：
重点表现道路、地形、视线、资源、怪物活动区、区域地标和中央决赛庭；
优先保证导航和战斗可读性，再增加环境细节。

FINAL COURT / 决赛庭：
重点表现万劫三庭、天劫雷云、BOSS 舞台、环形平台和终局压迫；
中心留出足够战斗空间，技能预警和角色轮廓必须清晰。

CODEX / 图鉴：
背景使用低干扰的天庭或卷轴式东方神话环境；
角色、技能和装备信息区域保持稳定高度，不随 tab 内容变化，
不让背景装饰影响文字、图标和卡片识别。

无论选择哪种场景类型，都必须继承本文件的镜头、色彩、材质、空间层级、
东方神话身份、战斗可读性和性能约束。
