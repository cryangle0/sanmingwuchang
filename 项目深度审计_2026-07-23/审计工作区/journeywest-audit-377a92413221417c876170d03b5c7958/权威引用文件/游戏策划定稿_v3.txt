                      一、游戏概述
═══════════════════════════════════════════════════════════════════

  类型        30人 · MOBA + Roguelike + 大逃杀
  平台        手游（全球跨服）
  单局时长    18-20分钟（大逃杀）/ 12-15分钟（杀戮赛）
  题材        西游记（38英雄：14神族 + 24妖族）
  核心哲学    象棋围棋哲学——规则极简，策略无穷
  核心循环    杀怪→捡技能/装备→五行克制→活到最后/杀到分数

【背景叙事（开场文案，一句话世界观）】
  "天劫之下，诸神平等，法力尽归凡尘。"
  ——天劫降世，神佛妖魔的法力被压制到同一水平线。如来与
  小妖同场竞技的合理性由此成立：进了这张地图，谁都得从
  1级打起，靠捡起来的技能和装备重新证明自己。
  （2026-07-17定案：以此叙事解决lore强度问题，如来佛祖保留，
  不再因"lore过强"替换任何英雄。）

【槽位架构】

  槽位            数量    开局状态                操作
  ─────────────────────────────────────────────────────────
  主动技能槽      1       英雄专属主动            1个按钮释放
  被动技能槽      4       空的，从地图捡          自动触发

  ※ V1无天赋被动系统（V2扩展考虑）。英雄差异化靠五行属性+专属主动。

【主动技能规则】

  开局              英雄自带的专属主动
  地图捡到主动      弹窗二选一：换掉当前主动 / 扔掉不捡
  升级方式          不吃书，随玩家等级自动增强
  换英雄时          自动变成新英雄专属主动（旧主动消失）
  换下来的主动      直接消失，不能卖钱，不能掉落

【被动技能规则】

  开局              4个空槽
  捡到技能书(没学过)  直接学习，填入空槽
  捡到技能书(已学会)  自动升级+1级（同名书=升级，丛林乱斗经典）
  捡到技能书(4槽满)  弹窗让玩家选替换哪个（新书替换旧技能，旧技能消失）
  捡到技能书(已满级)  捡不起来，留在地上给别人
  最高等级          5级
  换被动            捡新的替换旧的，旧的直接消失
  换英雄时          被动全部保留
  换下来的被动      直接消失，不能卖钱，不能掉落

【技能宝石规则】

  作用              升级任意已学被动技能+1级（通用，不限技能）
  捡到宝石          弹窗显示4个被动槽，点哪个升哪个
  满级技能          灰色不可选（不会浪费宝石）
  全部满级时        捡不起来，留在地上给别人
  空槽              不可选（未学习的技能不能用宝石升）
  商店购买          土地公出售，250金/颗，每次刷新2颗（先到先得）

  技能书 vs 宝石的区别：
  - 技能书 = 定向升级，只能升这个技能（运气好正好捡到想要的）
  - 宝石   = 自由升级，选任意技能升（运气差时用宝石保底）
  - 两条路互相补充，不冲突

【技能书与宝石掉落表】（2026-07-17 修订：提高爆率+定向倾向）

  怪物              被动技能书      技能宝石        主动技能        其他
  ─────────────────────────────────────────────────────────────────
  小野怪（普通）    10%概率1本      30%概率1颗      不掉            金币+经验
  飞行小怪          20%概率1本      30%概率1颗      不掉            金币+经验
                    （倾向移动类）
  肥猪              55%概率1本      60%概率1颗      不掉            金币
                    （倾向经济/特殊类）
  精英BOSS·肉盾型   必掉1本         必掉2颗         10%概率1个      金币+装备
                    （倾向生命力类）
  精英BOSS·输出型   必掉1本         必掉2颗         10%概率1个      金币+装备
                    （倾向攻击类）
  超级BOSS          必掉2本         必掉3颗         必掉1个         金币+装备
                    （随机）
  天降宝箱          —               —               —              必掉1金装+大量金币

  怪物类型          倾向掉落的被动技能类型
  ─────────────────────────────────────────────────────────────

  精英BOSS·肉盾型   生命力类（闪避、铁皮、护盾、嗜血、假死、

  精英BOSS·输出型   攻击类（冰霜、麻痹、击退、致盲、眩晕、暴击、

  - 玩家发现"打飞行怪老出移动技能""肥猪老出经济技能"等规律

  - 核心技能能练到5级，辅助技能3-4级

【技能设计哲学】
  每个技能改变"怎么打"，不是"打多疼"。
  - 被动有8种不同触发条件：
    命中时 / 被命中时 / 击杀时 / 静止蓄力 / 靠近石头 / 残血时 / 从背后 / 脱战时
  - 主动技能创造"moment"：
    钩拉、封路、替身、冻结等，不是"按了多打30%"
  - 技能和地图机制联动（石头伏击、迷雾、击杀节奏）

【装备槽】

  装备槽            3       身上穿的装备
  手牌格(暂存位)    1       暂存捡到的装备，可卖/可换/死亡掉落

【装备规则】

  品质              白 / 蓝 / 紫 / 金 四档
  同名唯一          同名装备只能穿1件
  可叠加            不同名装备可叠（如3双不同鞋）
  获取              商店购买（土地公/鞋匠）/ BOSS掉落 / 拾荒玩家掉落
  出售              只能在商店卖（土地公或鞋匠），不能随地卖
  丢弃              随时可丢弃（清空手牌格，但无回报）
  无升级            不合成不强化，只替换更好的
  手牌格满时捡新    弹窗：替换身上某件 / 丢弃手牌格里的 / 取消不捡

【装备出售机制——核心设计】

  操作          在哪能做        给钱吗
  ─────────────────────────────────────
  捡装备        任何地方        不给钱（捡起来）
  丢弃装备      任何地方        不给钱（直接消失）
  卖装备        只能在商店      给钱（土地公或鞋匠均可）

  说明：
  - 不能随地卖装备，必须带到商店才能换钱
  - 这创造了"拾荒者"玩法：
    团战打完地上有装备 → 捡起来放手牌格 → 带着跑找商店 → 卖掉换钱
  - 拾荒有风险：手牌格装备在1/2次死亡时会掉落
  - 丢弃功能解决"手牌格满又没商店"的尴尬（可扔但不给钱）
  - 丢弃(零回报) vs 卖掉(有回报) 之间的选择就是玩法

【手牌格的作用】
  1. 缓冲区：捡到装备不必立刻决策，可暂存对比
  2. 经济中转：捡起来放手里，带到商店卖钱（拾荒者玩法）
  3. 死亡风险载体：1/2次死亡掉手牌格装备

【装备掉落表】（2026-07-18 v4回调定稿）

  怪物          是否掉装备    品质概率
  ─────────────────────────────────────────────
  小野怪        不掉          只给金币+经验+技能书
  肥猪          20%概率掉     60%白 / 30%蓝 / 10%紫
  精英BOSS      65%概率掉     35%白 / 40%蓝 / 25%紫
  超级BOSS      必掉1件       70%紫 / 30%金（+金箍棒独立5%）
  天降宝箱      必掉1件       100%金
  玩家第3次死   掉全身装备    品质=对方穿的

  定位原则：装备有稀缺性（模拟实测20.3件/局，金装3.1件），
  但装备是决胜的重要支持、不是决胜核心——战力轴排序：
  等级 > 技能build > 五行 > 装备。
  完整装备表见《装备系统完整设计_v1.txt》（v4内容，44件）。

【死亡流程】

  第1次死    灵魂飞回复活点(5-8秒,沿途揭开战争迷雾)
            → 自动复活 → 3秒无敌
            掉落：手牌格里暂存的装备（如有）

  第2次死    同上
            掉落：手牌格里暂存的装备（如有）

  第3次死    彻底淘汰，结算排名
            掉落：身上全部3件装备

  ※ 技能永远不掉。
  ※ 死亡惩罚有梯度：前两次小亏(掉暂存)，第三次大亏(掉全身+出局)。
  ※ 掉落的装备留在地上，其他玩家可捡走（拾荒连锁效应）。

【灵魂飞回机制】
  - 死亡后变灵魂，从死亡点飞回复活点，耗时5-8秒
  - 飞行路径上揭开战争迷雾（可侦查沿途敌情，但只看几秒）
  - 到达复活点后自动复活，3秒无敌

═══════════════════════════════════════════════════════════════════
                  十、商店系统（四类商店）
═══════════════════════════════════════════════════════════════════

  三类商店均为随机位置出现，停留3分钟后消失，下次随机刷新。
  所有人共用（公共，非私人），先到先得。
  黑山老妖同样随机刷新，但功能是赌博而非买卖。

【土地公商店（装备+消耗品+宝石）】
  功能：买装备 + 买消耗品 + 买宝石 + 卖装备

  卖给玩家（装备）：
  - 白/蓝/紫装备
  - 每次刷新固定1件紫装（先到先得，卖完为止）
  - 无金装出售（金装只能BOSS/宝箱掉落）
  - 其他装备随机刷新（白/蓝为主）

  卖给玩家（消耗品）：
  - 千里眼符：揭开周围15m视野10秒，售价300金
  - 照妖镜：揭开周围20m内所有隐身单位3秒，售价500金
  - 消耗品买了即用，不占背包/手牌格

  卖给玩家（技能宝石）：
  - 每次刷新固定2颗宝石，250金/颗（先到先得）
  - 宝石可升级任意已学被动技能+1级
  - 买宝石 vs 买装备抢同一笔金币——策略选择

  回收玩家装备：
  - 所有品质装备均可卖钱换金币
  - 卖价根据品质定（具体数值待定）

【鞋匠（鞋子+消耗品+装备回收）】
  功能：买鞋子 + 买消耗品 + 卖装备

  卖给玩家（鞋子）：
  - 只卖鞋子（白/蓝为主，偶尔紫鞋）
  - 鞋类品种比土地公更多（想堆移速找鞋匠）
  - 鞋匠不卖非鞋类装备

  卖给玩家（消耗品）：
  - 千里眼符：揭开周围15m视野10秒，售价300金
  - 照妖镜：揭开周围20m内所有隐身单位3秒，售价500金
  - 与土地公同价，两个地方都能买

  回收玩家装备：
  - 所有品质装备均可卖钱（第二个卖装备点）
  - 给拾荒者多一个出售渠道，降低"找不到商店"的挫败感

【太白金星（英雄置换）】
  功能：换英雄

  服务内容：
  - 花金币换英雄（具体费用待定）
  - 可换不同英雄（换天赋打法）
  - 也可换同英雄（刷新专属主动）

  换英雄保留：被动技能×4、玩家等级、装备、金币
  换英雄替换：主动技能→新英雄专属
  有冷却时间（具体CD待定）

  ※ 商人天赋(卖价+20%)只影响卖装备，不影响换英雄费用

【消耗品说明】
  千里眼符和照妖镜为一次性消耗品，买了立即使用，不占任何槽位。
  - 千里眼符：通用视野，看附近有没有人
  - 照妖镜：专门破隐身，克制石遁/影遁天赋的伏击
  - 两个商店都卖，价格相同，方便玩家就近购买

【黑山老妖（赌博商店）】
  功能：赌技能/赌装备/赌主动/赌金币——高风险高回报

  刷新方式：随机位置出现，停留3分钟后消失（和其他商店一样）
  每局限次：3次（赌徒天赋英雄可赌5次）
  核心理念：大赢概率低(10-15%)但回报极诱人，输了还想来

  ── 赌被动技能（从4个槽里选一个下注）──
  大赢 15%：随机换一个你没有的技能（可能是强力技能）
  平   50%：随机换一个同级别技能（可能更好也可能更差）
  输   35%：技能直接消失，槽位变空

  ── 赌装备（从3个装备槽或手牌格选一件下注）──
  大赢 15%：升一级品质（白→蓝→紫→金）
  平   40%：换一件同品质随机装备
  输   45%：装备直接消失

  ── 赌主动技能（赌你当前的主动）──
  大赢 10%：随机换一个其他英雄的专属主动（超稀有）
  平   50%：换一个通用主动
  输   40%：主动变回你英雄的默认专属（不亏不赚）

  ── 赌金币（你选下注金额）──
  大赢 20%：获得2倍金币 或 随机一件紫装
  平   40%：返还本金
  输   40%：输掉一半本金

  赌徒天赋英雄加成：
  - 每局可赌5次（别人3次）
  - 大赢概率+10%
  - 打法：疯狂赌，要么神装要么裸奔

  心理设计要点：
  - 大赢概率必须低(10-15%)，否则变稳定收益就不刺激
  - 一局3次赌，可能一次都不赢，也可能第一次就赢
  - 这种不确定性是上瘾核心

                  十二、操作设计（手游极简）
═══════════════════════════════════════════════════════════════════

【操作按钮】

  移动          左摇杆
  普攻          1个按钮（自动选最近敌人）
  主动技能      1个按钮
  拾取/交互     自动触发弹窗（走过去即触发）

  总计：摇杆 + 2按钮。拾取/替换/卖买均通过弹窗，不占常驻按钮。

【位置暴露规则（游戏底层设定）】
  - 对玩家造成伤害后，攻击者位置在小地图上暴露3秒
  - 远程英雄30m射程优势被此规则部分抵消：打人即暴露，近战有反制窗口
  - 这是远程/近战平衡的核心底层机制，不作为技能，作为游戏规则

【弹窗交互】

  捡到主动技能          "换掉当前 / 扔掉"
  捡到技能书(没学过)    直接学会，填入空槽
  捡到技能书(已学会)    自动升级+1级（无弹窗）
  捡到技能书(4槽满)     "选一个替换 / 取消"
  捡到技能书(已满级)    捡不起来（无弹窗）
  捡到技能宝石          "点哪个技能升哪级 / 取消"（满级灰色不可选）
  捡到装备(手牌格满)    "替换身上某件 / 丢弃手牌格里的 / 取消"
  遇到土地公            商店界面（买装备/买消耗品/买宝石/卖装备）
  遇到鞋匠              商店界面（买鞋子/买消耗品/卖装备）
  遇到太白金星          换英雄界面（选英雄/确认）
  遇到黑山老妖          赌博界面（选下注物/确认/显示概率/摇骰子结果）

  ※ 捡装备弹窗无"卖掉"选项——卖装备必须去商店
