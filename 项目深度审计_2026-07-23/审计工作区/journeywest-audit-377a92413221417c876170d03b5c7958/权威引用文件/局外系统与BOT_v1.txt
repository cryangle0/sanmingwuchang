═══════════════════════════════════════════════════════════════════
                  一、局外最小核心（5件套）
═══════════════════════════════════════════════════════════════════

【1. 隐藏分匹配（MMR）】删掉会死：新手被屠→次日留存崩
  - 内部ELO式积分，按名次+击杀调整，玩家完全不可见
  - 匹配只用它分池；显示层没有任何段位（V1无排位，见V2）
  - 新手另有BOT保护（见第二节）

【2. 修为境界（只涨不掉的生涯进度）】删掉会死：无长期目标感
  - 每局按 名次分+击杀分+参与分 获得"修为"，只增不减
  - 境界：凡人→炼气→筑基→金丹→元婴→化神→大罗→齐天
    （8境×3层=24档，名字挂在头像框上）
  - 本质是"总游玩量的可炫耀化"。不是排位：无赛季无降级无焦虑，
    排位赛留给V2商业化配套
  - 齐天境预计需500+局——头部玩家的身份勋章

【3. 图鉴收集】删掉会死：Roguelike的长线钩子
  - 三册：技能图鉴104格 / 英雄图鉴38格 / 装备图鉴41格
  - 每格三档印记：见过(灰)→用过(银)→精通(金)
    精通=该技能升到5级 / 该英雄进过前3 / 该装备穿着进过前3
  - 收集进度给称号（"百技通"=100技能用过等）
  - 零新增美术内容，全部复用局内素材——性价比之王
  - 隐藏一手：定向掉落规律不写进图鉴。图鉴只记录"你用过什么"，
    不告诉你"去哪刷"——摸规律的乐趣留在社区

【4. 每日三签（轻任务）】删掉会死：次日回访理由
  - 每天3条，完成给修为+头像框素材，15分钟内可清完
  - 任务模板全部指向"换个玩法"：用木属性英雄玩1局 /
    一局内学会2个新被动 / 在黑山老妖赌1次 / 卖出3件装备
  - 刻意不做"赢X局"类任务——任务是探索引导器，不是胜负压力源

【5. 局后点赞】删掉会死：30人同服的最低社交温度
  - 结算界面可给本局任意玩家点赞（击杀你的人也能赞——
    "杀得漂亮"文化）
  - 赞数进个人主页。V1社交仅此而已：无好友、无聊天、无公会
    （全球同服跨语言，文字社交=翻译+审核成本黑洞，V2再议）

【商业化设计（2026-07-17 用户拍板改版：无限接近0但不为0）】

  立场修订：本作底色是RPG×竞技，不是硬核纯竞技。付费可以
  触碰数值，但每一件付费品都必须自带"平衡代价"或"硬上限"，
  把付费优势压在"感知得到、碾压不了"的区间。

  ── 四类付费品（V1预留接口，V1.5开闸）──

  1. 飞行坐骑（永久道具，旗舰付费点）
     效果：脱战8秒后升空低空飞行（无视地形），进入战斗立即落地
     代价：装备坐骑期间生命上限-8%（凡胎乘云，须减重轻身——
           设定自洽，且是玩家自愿佩戴的显性代价）
     边界：比金装筋斗云弱（筋斗云5秒起飞+35移速无代价）——
           当局捡到的神装永远强于花钱买的常驻，局内尊严保住
     lore：孙悟空有筋斗云、哪吒有风火轮，会飞本就是西游正统

  2. 英雄卡槽（永久解锁，3选1→4选1→5选1两档）
     效果：开局候选池扩大，纯选择权
     边界：不改属性不改掉落，只是"更容易开出想玩的流派"——
           便利型付费的天花板样本

  3. 复活币（消耗品，每局限用1枚）
     效果：第3次死亡时原地复活（3秒无敌），相当于第四条命
     代价：第3次死亡的掉落照常发生——复活时已掉光全身3件装备，
           裸装归来，技能保留
     边界：单局限1枚杜绝无限买命；裸装复活=数值上接近
           "多一次参与权"而非"多一条战力"；
           监控M10：复活币使用者胜率增幅>+15%则再加代价

  4. 皮肤微属性（王者荣耀模式，带动皮肤大盘）
     效果：每款皮肤固定附带一条微属性三选一设计：
           攻击+2 / 生命+30 / 移速+3（≈满级面板1.3%-1.7%）
     边界：同英雄多皮肤不叠加（只取穿戴那款）；
           微属性总量永久锁死在此量级，后续皮肤只换外观
           不涨数值——防"属性通胀"写进设计宪法

  ── 护栏（总设计师保底条款）──
  - 局内获取的一切（技能/装备/等级）永远强于任何付费品
  - 付费品不进技能池/装备池/掉落池——两套系统物理隔离
  - V2排位模式可一键关闭微属性与坐骑（竞技纯度阀门，备而不用）
  - 广告位（新兴市场）：看广告=1次免费re-roll或复活币折扣，
    广告可得的付费品必须全部可广告获取（防纯钞能力墙）

  ── 其余预留 ──
  - 皮肤体系：换色→主题皮肤（美术到位即开）
  - 战令：修为轨道旁挂付费轨道，结构已兼容
  - 新英雄：38→42+，付费/广告解锁位已预留

                  二、BOT系统（前期必备，用户确认）
═══════════════════════════════════════════════════════════════════

【填充规则】
  - 匹配等待20秒未满30人→BOT补足开局，等待期间不显示人数
  - 新手保护：账号第1局 27BOT / 第2-3局 22BOT / 第4-6局 12BOT，
    之后按真实池匹配。前几局的"我好强"是留存的第一推动力
  - MMR越高BOT越少：高分池仅在深夜/小区服凑不齐时补BOT

【BOT难度五档（D1-D5，按对局MMR选配）】

  档位  瞄准误差  反应延迟   会做的事
  ─────────────────────────────────────────────
  D1    大        1.2秒      刷野、捡书、天劫外逃跑
  D2    中        0.9秒      +使用主动技能、残血撤退
  D3    中        0.6秒      +简单build倾向、抢肥猪、逛商店
  D4    小        0.4秒      +绕后、蹲石头、抢宝箱、换装备决策
  D5    小        0.3秒      +技能连招、卡天劫边、终局拉扯

【行为设计要点】
  - BOT跑在服务端Sim内，走与玩家相同的操作接口
    （ClaudeCraft"同一Sim三宿主"架构天然支持，RL环境接口
    未来可训练D5档）
  - 人味三件套（防"一眼假"）：
    a. 移动带噪声——不走直线最优路径，偶尔停顿看似"犹豫"
    b. 决策带性格——每个BOT随机分配画像（怂/贪/莽/赌），
       怂的见人跑，赌的真去黑山老妖下注
    c. 失误带节奏——会空技能、会追杀过深、会捡"错误"的书
  - BOT经济/掉落/三条命与玩家完全同规则（BOT掉装备可捡，
    杀BOT给赏金——它们是生态的一部分，不是布景）

【命名池】
  - 取西游全书小妖名：奔波儿灞、灞波儿奔、精细鬼、伶俐虫、
    刁钻古怪、古怪刁钻、巴山虎、倚海龙、兴烘掀、掀烘兴、
    有来有去、云里雾、雾里云、急如火、快如风……（100+可考）
  - 原著粉会心一笑，普通玩家看着像抽象网名——两层都赢
  - 不加"Bot"标识、不用真人常用名格式，结算不标注
    （行业通行做法；玩家举报某BOT"像人机"时客服话术另定）

                  三、区域服与全球互通（用户确认方向）
═══════════════════════════════════════════════════════════════════

  - 区域分服：亚太 / 中国 / 欧洲 / 美洲 / 中东非，各区独立
    对局池，账号数据全球互通（换区保留一切局外进度）
  - 延迟目标：区内P95 ≤ 80ms。0.8秒级硬控、1.5秒天火预警、
    弹道躲避在此延迟下均可操作（已按20Hz tick+客户端插值核算：
    一个tick 50ms，80ms延迟≈落后1.6tick，服务器权威+客户端
    预测表现可接受）
  - 本地化：文字全量翻译（首发：简中/繁中/英/日/韩/葡/西/印尼/
    阿拉伯），语音不做——游戏内零剧情语音，成本趋零
  - 五行/西游概念出海处理：五行图标常驻显示克制箭头，
    不依赖文化背景也能3秒看懂（有手就会哲学的一部分）

                  四、性能预算（千元机达标线，用户确认）
═══════════════════════════════════════════════════════════════════

  参照：本作复杂度远低于和平精英（100人/3D写实/载具/万米地图）。
  30人+低模卡通渲染+约1.5km²地图，千元机是宽裕目标。

  【服务端】20Hz tick（ClaudeCraft现成）。同屏实体预算：
    30英雄 + 107野怪存量 + 召唤物峰值约40 + 弹道/掉落物
    ≈ 250实体/tick，Node单Sim可承载；兴趣范围快照(120码)
    天然限制下行带宽

  【客户端硬约束（写进开发规范）】
    - 每玩家自有召唤物上限9（豆兵3+狼灵2+火灵2+石像1+石卫1
      的理论满配），超出顶掉最旧——现设计天然≤9，规则兜底
    - 同屏特效分级：30米外DoT/残影/火灵只画简化版（LOD）
    - 战争迷雾+兴趣范围让同屏实际渲染实体通常<40
    - 目标帧率：千元机30fps稳定，中端机60fps
