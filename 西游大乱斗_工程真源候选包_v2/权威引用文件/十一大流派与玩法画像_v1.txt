本文档为设计的"玩家视角总纲"：101技能+44装备的存在意义
最终都落在这11条通往胜利的路上。流派不是系统，是玩家用
自我意识和创意在规则里踩出来的路——超高自由度，通往胜利
有无限可能。任何新增技能/装备必须回答：它喂养哪条路？

                  流派详解（配装均为现行定稿名词）

【1 纯战斗流】正统硬刚，刀刀到肉。
  英雄：孙悟空/二郎神/牛魔王/虎力大仙（刺客/战士模板）
  主动：大闹天宫 / 天眼 / 旋风 / 箭雨D9 / 电链D10
  被动：暴击B6 + 溅射B7 + 斩杀B10 + 连击B11
  装备：精铁棍 → 磨刀石 → 七星剑/血玉葫芦 → 雷公凿/金箍棒
  高光：废除"单刀一被动"后，暴击+连击+溅射同刀齐爆
  （模拟：四被动一刀双爆10.3%、三爆2.3%）——数字跳出来的解压瞬间
  克制：召唤流（溅射清兵）、坦克流（暴击破盾+斩杀）
  被克：刺客伏击流（找不到人）、移速风筝流（追不上）

【2 召唤大军流】带兵打仗的将军感。
  英雄：黄眉老祖（石罗汉）/黄袍怪（缠身）/战士坦克模板
  主动：豆兵D19 / 石罗汉 / 缠身
  被动：狼灵B12 + 火灵B13 + 石像B39 + 共鸣B37
  装备：驭兽鞭 → 招魂幡 → 万年灵芝 → 顺风耳
  峰值编制：2狼+2火灵+1石像+3豆兵+1石罗汉=9单位（上限规则G-R7）
  克制：坦克流（打不完）、刺客流（不知道打谁）
  被克：纯战斗流（溅射清兵）、天劫流（雷劈清兵不劈野怪但劈召唤物？
  ——规则明确：天劫只攻击英雄，召唤物免疫；此克制改为
  "AOE型英雄清兵"，原稿天劫克召唤作废）

【3 养成刷子流】前期苟，后期山。
  英雄：战士/坦克模板
  主动：聚财D16 / 妙手空空D15 / 淘金狂热D18
  被动：强韧B40 + 贪婪B32 + 寻宝B33 + 利息B34
  装备：狼牙棒 + 聚宝袋 → 万年灵芝 → 噬魂戒（金）
  双修终极：强韧(生命无限涨) + 噬魂戒(攻击无限涨)——
  一被动一金装，血与刀的对偶成长
  克制：坦克流（我比你肉）、经济流（我刷得快）
  被克：刺客流（发育期被抓）、战斗流（前期被压）

【4 经济碾压流】玩的是大富翁。
  英雄：连弩/移速型
  主动：妙手空空D15 / 聚财D16 /（换英雄取砸钱·银角大王）
  被动：偷钱B31 + 贪婪B32 + 利息B34 + 拾荒B35
  装备：聚宝袋 → 布袋 → 判官笔 → 聚宝盆（金）
  张力：利息鼓励攒钱，但击杀奖励含"死者持有金币10%"——
  钱包越鼓越被猎杀，攒与花的抉择贯穿全局
  克制：养成流（更有钱）、坦克流（装备碾压）
  被克：刺客流（被秒）、战斗流（前期被压）

【5 刺客伏击流】猎人般的紧张感。
  英雄：白骨精（借尸还魂）/大鹏雕（金翅俯击）/六耳猕猴（六耳幻身）
  主动：借尸还魂 / 金翅俯击 / 潜行D7
  被动：背刺B26 + 伏击B29 + 暴击B6 + 疾跑B27
  装备：精铁棍 → 七星剑 → 夜行斗篷 → 金箍棒
  一刀上限：背后首击=背刺70%+伏击70%再×暴击倍率，极限破千
  克制：远程流/经济流（脆皮）
  被克：坦克流（秒不掉被反杀）、天劫流（缩圈无处蹲）、
        照妖镜/照妖珠持有者
  ※ 反制链完整：铜镜（背刺/伏击加成伤害减半）+照妖珠+照妖镜
    三层反制在售——刺客强但可反制，不做压制性流派

【6 坦克磨血流】不动如山。
  英雄：黑熊精（黑风罩）/唐僧（袈裟）/灵感大王（冻河）
  主动：铁布衫D22 / 袈裟 / 冰棺D21 / 行愿（换普贤菩萨）
  被动：铁皮B16 + 护盾B17 + 反伤B22 + 回复B21
  装备：虎皮裙 → 万年灵芝 → 荆棘甲
  反伤峰值：反伤被动25%+荆棘甲20%=45%反弹且可暴击——
  打我的人自己流血
  克制：战斗流、刺客流（反杀）
  被克：移速风筝流（打不到）、砸钱真伤（无视减伤）、
        降魔杵持有者（对高血目标+20%）

【7 移速风筝流】溜人的快感。
  英雄：长弓/连弩模板（射程即生命线）
  主动：闪现D6 / 虎箭（虎力大仙）/ 三昧神风（黄风怪）
  被动：奔腾B36 + 残影B30 + 疾跑B27 + 猎杀B28
  装备：千里靴/登云履 → 疾风靴（免疫减速）→ 筋斗云（金）
  移速无上限（G-R2已废除）：天劫收束+控制链是天然克制，
  规则不设限，玩家自由开发极速玩法
  克制：坦克流、战士（追不上）
  被克：刺客流（瞬移贴脸）、天劫终局（空间归零）、硬控链

【8 赌狗摸奖流】每刀都是抽卡。
  英雄：任意攻击型（换英雄取银角大王砸钱亦可）
  主动：轮盘D11 / 大闹天宫
  被动：暴击B6 + 连击B11 + 眩晕B5 + 假死B19
  装备：赌坊金牌（大赢概率翻倍）——赌狗流的深度由轮盘/假死/黑山老妖承担
  数学底：赌金币公平赌局（EV≈1.0），赌坊金牌大赢翻倍后为正EV——赌狗流是真实成立的数学流派
  克制：任何流派（运气好） | 被克：任何流派（运气差）

【9 赏金复仇流】死亡是复仇的开始。
  英雄：攻击/移速型
  主动：标记D12 / 连赏D17
  被动：赏金B41 + 悬赏B42 + 猎杀B28 + 伏击B29
  装备：夜巡灯 → 判官笔 → 七星剑
  循环：被杀→凶手顶1500金赏金+全图小地图闪烁→全服帮你
  追杀→你击杀赏金目标CD-30秒+移速40%→连锁猎杀
  克制：连杀流（越连杀越被全图追杀）
  被克：刺客流（杀完就消失）

【10 天劫主宰流】逆流而上，雷暴中的猎手。
  英雄：坦克/战士模板（沙和尚流沙联动）
  主动：雷击D3 / 三昧神风 / 流沙
  被动：避雷B43 + 雷暴B44 + 疾跑B27 + 铁皮B16
  装备：避雷木牌 → 登云履 → 渡劫铃（金）
  数据：满配天劫区生存165秒（对手36秒）——圈是你的主场，
  但P10=111秒，天劫永远可能翻脸
  克制：移速流（圈边截杀）、坦克流（20%最大生命雷伤）
  被克：刺客流（蹲守时被绕后）、安全区战斗流（不进圈你白配）

【11 陷阱猎人流】请君入瓮。
  英雄：移速/攻击型
  主动：陷阱D20（唯一硬需求，地图掉落）
  被动：伏击B29 + 猎杀B28 + 疾跑B27 + 背刺B26
  装备：夜巡灯 → 夜行斗篷 → 顺风耳
  点位学：肥猪房门口/商店旁/缩圈必经之路——地图知识变现
  克制：肥猪流、跑圈流
  被克：位移技能（跳过陷阱）、照妖镜购买者

【克制环（无无敌流派）】
  战斗 克 召唤 ；刺客 克 远程/经济/风筝 ；坦克 克 刺客/战斗 ；
  风筝 克 坦克 ；天劫 克 风筝/坦克 ；刺客 克 天劫（蹲守被绕后）；
  赏金复仇 克 连杀型战斗 ；陷阱 克 跑图型 ；位移 克 陷阱。
  修订1处：原稿"天劫克召唤（雷劈小弟）"作废——规则明确
  天劫只劈英雄；召唤流的克制方改为AOE英雄（旋风/三昧神风/箭雨）。

【预期胜率格局（M9监控带：均值±40%）】
  上位主流：纯战斗 / 刺客 / 坦克（成型易，直觉强）
  运营位：养成 / 经济（低端局强，高端被针对——发育型玩家
          自带"行走的赏金"，系统性反制已内置于击杀经济）
  娱乐位：赌狗 / 天劫（胜率偏低但节目效果拉满，有意为之——
          它们的存在价值是"每局都可能发生离谱的事"）
  技术位：风筝 / 赏金 / 陷阱 / 召唤（操作与知识变现）

【流派切换（超高自由度的落地机制）】
  - 被动切换：捡新书替换，零金币成本（机会成本=旧技能消失）
  - 主动切换：地图捡取弹窗二选一，随时改向
  - 英雄切换：太白金星1500金/CD120秒——中期转型的定价
  - 装备切换：商店买卖流转
  典型转型路径：
    养成流刷到12分钟满级 → 换战斗流配装出山收割
    经济流攒到12000金 → 一波买紫装转战斗流"暴发户出山"
    第一次死亡后 → 顺势转赏金复仇流（被动条件自动满足）
    捡到陷阱D20 → 从任何流派转陷阱猎人
  设计自检：11条路互相可达，转型成本存在但不禁止——
  "规则简单，变化无穷"的最终体现。
