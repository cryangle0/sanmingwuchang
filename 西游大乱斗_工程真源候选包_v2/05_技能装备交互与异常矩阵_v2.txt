      05 · 技能装备交互与异常矩阵 v2 （P0-10伤害标签重构版）
═══════════════════════════════════════════════════════════════════
取代v1单一标签制。五个正交字段, 每次伤害事件必须五字段齐全:

【1 五字段定义】
DamageForm:    NORMAL(普攻) / SKILL / DOT / TRUE / PCT(百分比生命)
SourceFaction: PLAYER / MONSTER / ENVIRONMENT
Delivery:      MELEE / PROJECTILE / GROUND_AOE / REFLECT / AURA
CreditOwner:   玩家ID / 怪物ID / ENV(无归属)
TriggerMask:   位集{ON_HIT, ON_STRUCK, LIFESTEAL, REFLECTABLE,
               ELEM(吃五行), MITIGABLE(吃减伤), SHIELDABLE(护盾可吸)}

【3 由字段推出的通则(取代v1通则, 修正2条)】
G1 REFLECT不再触发REFLECT(字段自锁) ✓
G2 DOT吃五行/百分比减伤/固定减伤(MITIG✓), 每跳不触发受击被动——
   与v1"G01 DoT免固定减伤"不同: v2统一走MITIG, 虎皮裙克DoT登记为
   已知克制关系(坦克身份), 非bug
G3 怪物伤害触发玩家受击链(修正v1把怪物混入ENV导致受击被动对怪失效的
   潜在bug——这是审计P0-10指出的真实交互隐患)
G4 ENV伤害不触发受击链/不可反弹/不吃五行; 只有护盾与无敌可对抗
G5 击杀归属=CreditOwner字段唯一裁定; 怪物补刀=怪物击杀(锁定项);
   拉怪害人时怪物击杀无人得利; 反伤击杀归反弹者
G6 五行ELEM位: 仅 PLAYER↔五行猪/龙王 双向开启; 其余一律关闭
G7 暴击: 默认×2.0, 磨刀石×2.3, B06按等级1.8-2.3, 多源取最高;
   仅NORMAL与文本明示技能可暴击(冷箭是SKILL例外)
